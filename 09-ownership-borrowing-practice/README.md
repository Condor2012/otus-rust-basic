# Занятие 9. Практика: владение и заимствование

Сквозная задача из презентации — модель банка, закрепляющая RAII, владение, разделяемые и эксклюзивные ссылки.

## Что демонстрирует

- структуру `Account` с балансом `i64` и реализацией `Drop`;
- чтение аккаунта через разделяемую ссылку в `print_balance`;
- перевод средств между аккаунтами через две эксклюзивные ссылки;
- `destroy_account`, принимающую аккаунт по значению и переносящую его остаток перед автоматическим уничтожением;
- структуру `Bank`, владеющую `Vec<Account>`;
- начисление процентов: положительный баланс обрабатывается по `credit_rate`, отрицательный — по `debit_rate`;
- расчёт обязательств и активов банка через разделяемую ссылку;
- перемещение аккаунтов из одного банка в другой при `merge_banks`;
- документационные и модульные тесты.

Ставки задаются в базисных пунктах: `100` соответствует 1%, а `1` — 0,01%. Расчёт выполняется в целых числах с отбрасыванием дробной части.

## Запуск

```bash
cargo run --example demo
```

Запуск модульных и документационных тестов:

```bash
cargo test
```
