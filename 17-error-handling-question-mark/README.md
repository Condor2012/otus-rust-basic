# Занятие 17. Обработка ошибок. Оператор ?

Код организован вокруг четырёх слайдов **LIVE** из презентации.

## LIVE: паника

- `expect` для случая, когда отсутствие корректного значения считается программной ошибкой;
- тест `#[should_panic]`, показывающий поведение при нарушении контракта;
- отличие паники от возвращаемой и обрабатываемой ошибки `Result`.

## LIVE: Option

- `is_some` и `is_none`;
- `map`;
- `and` и ленивый `and_then`;
- `or` и ленивый `or_else`;
- `unwrap_or`, `unwrap_or_else` и `unwrap_or_default`;
- `unwrap` и `expect` только на заведомо корректном значении.

## LIVE: Result

- `is_ok` и `is_err`;
- `map` и `map_err`;
- `and` и `and_then` для последовательных вычислений;
- `or` и `or_else` для альтернативного результата;
- `unwrap_or`, `unwrap_or_else` и `unwrap_or_default`.

## LIVE: оператор ?

- извлечение значения из `Ok` и ранний возврат `Err`;
- последовательный разбор двух строк без вложенных `match`;
- ранний возврат `None` в функции, возвращающей `Option`.

Библиотеки `anyhow`, `thiserror` и `snafu` только упоминаются в презентации; этот пример использует стандартную библиотеку.

## Запуск

```bash
cargo run --example demo
```
