# Занятие 19. Обобщённое программирование. Статический полиморфизм

Примеры по презентации: один код работает с разными типами, а необходимые операции задаются ограничениями трейтов на этапе компиляции.

## Что демонстрирует

- обобщённую структуру `Pair<T>`;
- обобщённые функции `add`, `largest` и `print_display`;
- ограничения `Add<Output = T>`, `PartialOrd` и `Display`;
- собственный трейт `IsNearlyZero` и его реализации для `i32`, `f32` и `Point`;
- обобщённое безопасное деление `safe_div`;
- реализации стандартных `Default` и `Add` для `Point`;
- пользовательский трейт `Klone` как пример явной реализации операции;
- сигнатуру в стиле `HashMap::get`: `Borrow<Q>`, `Hash + Eq` и `?Sized` для поиска `String` по `&str`.

## Мономорфизация

Для каждого использованного сочетания обобщённых параметров компилятор создаёт конкретную реализацию. Например, вызовы `add` с `i32` и `String` порождают разные специализации. Динамическая диспетчеризация при этом не требуется, но увеличиваются объём генерируемого кода и время компиляции.

## Запуск

```bash
cargo run --example demo
```

Запуск тестов:

```bash
cargo test
```
