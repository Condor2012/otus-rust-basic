# Занятие 34. Практика: потоки, куча, mutex, atomic

Восемь задач со слайдов презентации. Основа каждого модуля — решение по ссылке «РЕШЕНИЕ» на соответствующем слайде. Для повторного использования и тестирования код решений вынесен из `main` в функции `run`.

## Задачи

| № | Задача | Используемые средства | Модуль |
|---|---|---|---|
| 1 | Привет, потоки! Пять потоков и ожидание их завершения | `thread::spawn`, `JoinHandle::join` | `hello_threads.rs` |
| 2 | Сумма первых трёх и последних двух чисел | `move`, возврат значения из потока | `sum_in_threads.rs` |
| 3 | Общий неизменяемый счётчик для трёх потоков | `Arc` | `shared_counter.rs` |
| 4 | Четыре потока по пять увеличений счётчика | `Arc<Mutex<i32>>` | `mutex_counter.rs` |
| 5 | Четыре потока по десять атомарных увеличений | `Arc<AtomicI32>`, `fetch_add` | `atomic_i32_counter.rs` |
| 6 | Параллельная сумма двух половин вектора | `thread::spawn`, `move`, `join` | `parallel_sum.rs` |
| 7 | Десять потоков по сто увеличений без блокировок | `Arc<AtomicUsize>` | `atomic_usize_counter.rs` |
| 8 | Общий банковский счёт: пополнения и снятия | `Arc<Mutex<BankAccount>>` | `bank_account.rs` |

В решении восьмой задачи начальный баланс равен 1000. Пять потоков вносят `5 × 10 × 50`, пять потоков снимают `5 × 10 × 30`, поэтому итоговый баланс — 2000. Методы структуры принимают `&mut self`, как в исходном решении; доступ к ним из разных потоков защищён мьютексом.

Порядок вывода независимых потоков не гарантирован. В задачах со счётчиками используется `Ordering::SeqCst`, как в решениях со слайдов.

## Запуск

```bash
cargo run
cargo test
```

Внешние зависимости не используются.
