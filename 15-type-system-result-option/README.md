# Занятие 15. Система типов. Result, Option, ()

Примеры по презентации занятия: явное представление отсутствующих значений и ошибок в системе типов Rust.

## Что демонстрирует

- `Option<T>` для частичных функций и опциональных полей;
- оператор `?` для раннего возврата `None`;
- извлечение опционального поля через `Option::take`;
- безопасные альтернативы `unwrap`: `unwrap_or`, `map` и явный `match`;
- `Result<T, E>` и распространение ошибок через `?`;
- пользовательскую ошибку `MathError` с контекстом исходной `ParseIntError`;
- реализации `Display`, `std::error::Error` и `From<ParseIntError>`;
- вспомогательный алиас `MathResult<T>`;
- преобразование разных ошибок в `Box<dyn Error>`;
- unit-тип `()` как результат функции без содержательного возвращаемого значения.

Внешние библиотеки `anyhow`, `thiserror` и `snafu`, упомянутые в презентации, не используются: пример полностью построен на стандартной библиотеке.

## Запуск

```bash
cargo run --example demo
```
