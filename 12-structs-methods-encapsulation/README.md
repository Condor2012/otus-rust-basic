# Занятие 12. Структуры и методы. Инкапсуляция

Базовый пример структуры с приватным полем и методами — конструктором и геттером.

## Что демонстрирует

- инкапсуляцию: поле `value` приватно, доступ к нему возможен только через публичные методы;
- конструктор `MyStruct::new` и метод доступа `value`;
- создание экземпляра и чтение значения в запускаемом примере.

## Запуск

```bash
cargo run --example demo
```
