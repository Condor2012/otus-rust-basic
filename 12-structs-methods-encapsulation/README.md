# Занятие 12. Структуры и методы. Инкапсуляция

Базовый пример структуры с приватным полем и методами — конструктором и геттером.

## Что демонстрирует

- инкапсуляцию: поле `f2` приватно, доступ только через методы
- конструктор `new` и метод доступа `get_mystruct`

## Запуск

```bash
cargo run
```
