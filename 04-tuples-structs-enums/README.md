# Занятие 4. Сложные типы данных. Кортеж, структура, перечисление

Примеры кода по презентации «Сложные типы данных. Кортеж, структура, перечисление».

## Что демонстрирует

- Кортежи: доступ по индексу (`.0`, `.1`), вложенность, пустой кортеж `()`
- Структуры с именованными полями: создание, `pub`/`pub(crate)`, синтаксис `..`
- Структуры-кортежи и их тип-функция, юнит-структуры
- Перечисления: варианты трёх видов, доступ к данным через `match`
- Type layout: `size_of`/`align_of`, паддинг, атрибуты `#[repr(C)]`, `#[repr(align(8))]`
- Явные теги перечислений `#[repr(u32)]` и каст `as u32`

## Запуск

```bash
cargo run --example demo
```
