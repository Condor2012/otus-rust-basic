# Занятие 35. Interior mutability. Cell, RefCell

Мутабельность через неизменяемые ссылки: `Cell<T>` и `RefCell<T>`.

## Что демонстрирует

- `Cell::get/set/replace/take` — мутация значения через разделяемую ссылку
- `RefCell::borrow/borrow_mut` — динамическая проверка правил заимствования во время исполнения
- несколько читателей (`borrow`) одновременно

## Запуск

```bash
cargo run --example cell
cargo run --example refcell
cargo test
```

- `cell` — демонстрация `Cell`: `get/set/replace/take`
- `refcell` — демонстрация `RefCell`: `borrow/borrow_mut`, несколько читателей одновременно

## Ожидаемый вывод

`cell` показывает изменение значения и возврат прежнего значения через `replace`:

```text
Начальное значение: 5
После Set(10): 10
Через ссылку: 15
Replace(20): старое =  15, Новое = 20
Take(): забрали =  20, Осталось = 0
```

`refcell` демонстрирует изменение списка и два одновременных чтения:

```text
Начальное список: ["яблоко", "банан"]
Добавили апельсин: ["яблоко", "банан", "апельсин"]
После добавления: ["яблоко", "банан", "апельсин"]
Удалили последний элемент: ["яблоко", "банан"]
Финальный список: ["яблоко", "банан"]
Читатель 1: ["яблоко", "банан"]
Читатель 2: ["яблоко", "банан"]
```
