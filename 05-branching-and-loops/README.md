# Занятие 5. Ветвление и циклы

Примеры кода по презентации «Ветвление и циклы».

## Что демонстрирует

- Блок кода как выражение со значением
- `if` / `else if` / `else`, операторы сравнения, `if` как выражение
- `if let`, if-let-цепочки (Rust 2024)
- Циклы: `while`, `while let`, `loop`, `for`
- `break` и `continue`, `break` со значением из `loop`
- Диапазоны `0..10`, итерация по массиву, `enumerate`
- Метки циклов и блоков (`'label`), `break 'label` со значением
- Эмуляция do-while
- `match`: шаблоны, порядок веток, `_`
- Оператор `?` для `Option` и `Result`
- `let-else`

## Запуск

```bash
cargo run
```
