# Занятие 38. Продвинутые элементы синтаксиса

Рабочие примеры по темам презентации. Каждая тема вынесена в отдельный модуль и снабжена тестами.

## Содержание

| Модуль | Тема |
|---|---|
| `patterns.rs` | Исчерпывающий `match`, ветви для `enum`, диапазоны и связывание `x @ 1..=10` |
| `destructuring.rs` | Структуры, вложенные структуры, кортежи, срезы, `Option<Result<...>>`, `_` и `..` |
| `guards.rs` | Охранные выражения `if` ветвей `match`, в том числе с деструктуризацией `Point` |
| `let_patterns.rs` | `if let`, let chains, вложенный `Some(Ok(value))`, `while let` с итератором |
| `closures.rs` | `Fn`, изменяемый захват и `move`-замыкание |
| `attributes.rs` | `#[derive]`, `#[inline]`, `#[allow]`, `#[test]` |
| `lifetimes.rs` | Общее время жизни аргументов и результата, `Book<'a>`, `&'static str` |
| `associated_types.rs` | `Graph` с ассоциированными типами `Node` и `Edge` |
| `deref.rs` | Собственный `MyBox<T>`, `Deref`, `DerefMut`, deref coercion к `&str` |
| `conditional_compilation.rs` | Альтернативные реализации через `cfg`, `debug_assertions` |
| `traits.rs` | Супертрейт, ассоциированная константа, метод по умолчанию, blanket impl и обобщённый `Converter<T>` |
| `macros.rs` | Декларативный вариативный макрос `make_vec!` |

Процедурные derive- и attribute-макросы на слайдах показаны только как синтаксис и требуют отдельного proc-macro crate; они относятся к следующему занятию и здесь не реализованы.

В примере `longest` со слайда возвращается `y`, имеющий другое время жизни, поэтому исходная сигнатура не компилировалась бы. В рабочем примере обе входные ссылки и результат используют общее время жизни `'a`.

## Запуск

```bash
cargo run
cargo test
```

Внешние зависимости не используются. Ветки условной компиляции для других операционных систем можно проверить кросс-компиляцией на соответствующие target-платформы.
