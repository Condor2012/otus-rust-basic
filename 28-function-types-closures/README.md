# Занятие 28. Функции. Типы функций. Лямбда-функции

Пример показывает, как писать полиморфный код, принимающий обычные функции и лямбда-функции с разными способами захвата окружения.

## Содержание

- `function_pointers.rs` — тип `fn(i32, i32) -> i32`, передача именованных функций `add` и `multiply`, а также лямбды без захвата окружения.
- `closure_traits.rs` — обобщённые функции с границами `Fn`, `FnMut` и `FnOnce`.

## Разница между трейтами

| Трейт | Что разрешено лямбде | Пример |
|---|---|---|
| `Fn` | Читать захваченные значения, не изменять их | Умножение на захваченный `factor` |
| `FnMut` | Изменять захваченные значения | Увеличение захваченного `calls` или `total` |
| `FnOnce` | Забирать владение захваченным значением | Перемещение `String` из лямбды |

Иерархия: каждая `Fn` является также `FnMut` и `FnOnce`, а каждая `FnMut` — `FnOnce`. Поэтому `FnOnce` — самая широкая граница для однократного вызова, а `Fn` требуется, когда лямбду нужно вызывать многократно без изменения окружения.

Указатель `fn` хранит адрес функции и не содержит захваченное окружение. Лямбда без захвата может неявно преобразоваться в указатель на функцию; лямбда с захватом передаётся через обобщённую границу `Fn`, `FnMut` или `FnOnce`.

## Запуск

```bash
cargo run --example demo
cargo test
```

Внешние зависимости не используются.
