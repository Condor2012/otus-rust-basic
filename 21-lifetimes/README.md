# Занятие 21. Времена жизни

Примеры по презентации: время жизни описывает область, в которой ссылка гарантированно остаётся действительной. Проверка выполняется компилятором и предотвращает появление висячих ссылок.

## Что демонстрирует

- синтаксис `&i32`, `&'a i32` и `&'a mut i32`;
- функцию `longest<'a>`, где результат связан с временем жизни обоих аргументов;
- элизию времени жизни в `first_word`, где явная аннотация не требуется;
- структуру `LtStruct<'a, 'b>` с двумя независимыми ссылками;
- метод `get_ptr`, возвращающий ссылку с исходным временем жизни `'a`, а не временем жизни `&self`;
- статическое значение и строковый литерал со ссылками `&'static`.

Аннотации не продлевают существование значений: они описывают отношения между ссылками, позволяя компилятору проверить корректность кода по сигнатурам функций и типов.

## Запуск

```bash
cargo run
```
