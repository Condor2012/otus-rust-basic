# Занятие 37. Сборка. Модули

Небольшой каталог товаров разбит на логические блоки. Пример показывает перенос кода в отдельные файлы, вложенные модули и тестовый модуль.

## Структура проекта

```text
src/
├── main.rs         # запускаемая программа, использующая публичный API библиотеки
├── lib.rs          # корень библиотеки, подключение модулей и тестов
├── pricing.rs      # отдельный файл-модуль для расчёта скидки
├── tests.rs        # тестовый модуль, компилируется только для тестов
└── catalog/
    ├── mod.rs      # модуль каталога
    └── item.rs     # вложенный модуль товара
```

- `pub mod catalog;` и `pub mod pricing;` подключают файлы-модули к библиотеке.
- `mod item;` внутри `catalog/mod.rs` подключает вложенный файл `catalog/item.rs`.
- `pub use item::Product;` реэкспортирует тип, поэтому снаружи доступен путь `catalog::Product`.
- `#[cfg(test)] mod tests;` подключает `src/tests.rs` только при запуске тестов.
- Запускаемый пример `src/main.rs` использует библиотеку через её публичный API.

Тесты проверяют добавление и поиск товаров, расчёт общей стоимости, скидки и граничные значения процента.

## Запуск

```bash
cargo run
cargo test
```

Внешние зависимости не используются.
