# Занятие 2. Основы архитектуры компьютера

Примеры кода по мотивам лекции «Основы архитектуры компьютера»
(модели компьютера, процессор и память, стек и куча, параллельное исполнение).

## Что демонстрирует

- Статически выделенная память: `static` переменная живёт всё время работы программы
- Стек: локальные переменные функции и рекурсия (LIFO)
- Стек как структура данных «последним пришёл — первым ушёл»
- Куча: `Box` — отслеживающая структура, аллокация через аллокатор
- RAII: освобождение памяти при вызове `Drop`
- Указатели как адреса памяти: смотрим адреса переменных на стеке и данных в куче

## Запуск

```bash
cargo run --example demo
```
