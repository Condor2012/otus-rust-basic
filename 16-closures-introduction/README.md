# Занятие 16. Введение в лямбда-функции

Примеры по презентации: указатели на функции, замыкания и их состояние, способы захвата окружения, типажи `Fn`, `FnMut`, `FnOnce`, возврат и хранение замыканий.

## Что демонстрирует

- указатель на функцию `fn(u32) -> u64` без состояния;
- неявный и явный синтаксис сигнатур замыканий;
- захват переменной по эксклюзивной ссылке и изменение внешнего состояния;
- захват владения через `move`;
- принятие замыканий через `impl FnMut` и обобщённый параметр `F`;
- различия `Fn`, `FnMut` и `FnOnce`;
- возврат замыкания через `impl FnMut`;
- хранение замыкания в обобщённой структуре и через `Box<dyn Fn>`;
- Higher-Rank Trait Bound `for<'a>` для ссылок с разными временами жизни.

## Запуск

```bash
cargo run
```

Запуск тестов:

```bash
cargo test
```
