# Занятие 24. Практика: обобщённое программирование и времена жизни

Решения четырёх задач из материалов к занятию и связанного GitHub Gist.

## Lifetime #1: различия между предложениями

- `Difference<'a>` хранит слова, которые встречаются только в одном из предложений;
- `find_difference<'a>` связывает оба входа и возвращаемые ссылки общим временем жизни;
- `HashSet` убирает повторы, а сортировка делает результат детерминированным;
- тесты сохраняют исходный сценарий, где часть результата используется после уничтожения третьей строки, но в пределах времени жизни остальных входов.

## Tuple sum2

- `tuple_sum2` складывает первые два элемента кортежа;
- трейт `TupleSum2` реализован для кортежей длиной от двух до пяти;
- ограничение `A: Add<B, Output = A>` позволяет первому и второму элементам иметь разные типы, но гарантирует тип результата;
- поддержаны примеры с целыми числами, числами с плавающей точкой и дополнительными элементами других типов.

## Обобщённый математический вектор

- `Vector<T, const N: usize>` хранит массив фиксированной длины;
- `From<[T; N]>`, `new1`, `new2` и `new3` создают векторы;
- `len()` вычисляет евклидову длину для `f32` и `f64` через трейт `FloatNum`;
- трейт `Num` объединяет необходимые числовые операции и нулевое значение;
- `Add` складывает компоненты попарно, `Mul<T>` умножает вектор на скаляр;
- `std::array::from_fn` и `array::map` используются без внешних зависимостей.

## Lifetime #2: разбор и сопоставление шаблона

- `MatcherToken<'a>` представляет обычный текст, варианты `(one|two|three)` и wildcard `.`;
- `Matcher<'a>` заимствует исходный шаблон и хранит разобранные токены;
- `new` возвращает `None` для незакрытого списка вариантов;
- `match_string` возвращает ссылки на совпавшие токены и части проверяемой строки;
- отдельные времена жизни показывают, что результат зависит и от `Matcher`, и от входной строки;
- wildcard корректно потребляет один Unicode-символ через `len_utf8`;
- `most_tokens_matched` сохраняет лучший результат между вызовами.
