# Занятие 18. Практика: работа с Result, Option

Решения десяти отдельных задач из презентации.

## Option

1. `last_char` — последний Unicode-символ строки;
2. `safe_divide` — деление `f64` без деления на ноль;
3. `find_element` — индекс первого вхождения элемента;
4. `safe_sqrt` — квадратный корень только из неотрицательного числа;
5. `sum_options` — сумма двух значений через `and_then` и `map`.

## Result

1. `checked_divide` — деление с ошибкой `Division by zero`;
2. `parse_number` — разбор `i32` с ошибкой `Invalid number`;
3. `read_file_contents` — чтение файла с сохранением `std::io::Error`;
4. `validate_password` — проверка длины и наличия ASCII-цифры;
5. `sum_results` — сумма двух результатов с ранним возвратом первой ошибки через `?`.

Сигнатуры функций и тексты ошибок соответствуют условиям слайдов. Тесты включают приведённые примеры и дополнительные граничные случаи.

## Запуск

```bash
cargo run
```

Запуск тестов:

```bash
cargo test
```
