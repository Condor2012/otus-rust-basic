# Занятие 13. Перечисления и pattern matching

Примеры по презентации занятия: перечисления вместо числовых статусов, варианты с данными, исчерпывающий `match` и деструктуризация значений.

## Что демонстрирует

- перечисления `OrderStatus`, `Direction` и `TrafficLight`;
- `match` как выражение и импорт вариантов через `use OrderStatus::*`;
- варианты `Message` без данных, со структурными и кортежными данными;
- вычисление площади `Shape`, включая формулу Герона;
- альтернативы через `|`, диапазоны, `_` и match guards;
- деструктуризацию кортежей, структур и вложенных перечислений;
- `Option`, `if let`, `while let` и сопоставление срезов;
- калькулятор `Operation`, возвращающий `Result<f64, String>`;
- реализацию FizzBuzz через сопоставление кортежа остатков.

## Запуск

```bash
cargo run
```

Запуск тестов:

```bash
cargo test
```
