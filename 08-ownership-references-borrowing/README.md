# Занятие 8. Владение. Ссылки и заимствование

Пример по PDF занятия и пяти ссылкам на Rust Playground: указатели, разделяемые и эксклюзивные ссылки, правила заимствования, толстые ссылки и срезы.

## Что демонстрирует

- получение адреса значения через сырой указатель без небезопасного разыменования;
- разделяемые ссылки `&T`, которые позволяют читать значение, не забирая владение;
- эксклюзивную ссылку `&mut T` для изменения значения;
- завершение времени жизни разделяемых ссылок после последнего использования и последующее создание `&mut`;
- возврат владеющей `String` вместо невозможного возврата ссылки на локальную переменную;
- толстые ссылки `&str` и `&[u8]`, содержащие указатель и длину;
- получение второго слова как строкового среза без новой аллокации;
- автоматическое приведение `String`, `Vec<T>` и `Box<T>` при работе со ссылками и срезами.

Намеренно ошибочный пример с висячей ссылкой из презентации не воспроизведён как компилируемый код: Rust запрещает вернуть `&String`, указывающую на уже уничтоженную локальную строку.

## Запуск

```bash
cargo run --example demo
```
