# Занятие 39. Макросы: декларативные и процедурные

Пример состоит из основного crate и вложенного proc-macro crate. Декларативные макросы объявлены через `macro_rules!`; процедурные получают и возвращают `proc_macro::TokenStream`.

## Декларативные макросы

| Макрос | Что демонстрирует |
|---|---|
| `four!()` | Простейшее раскрытие в `1 + 3` |
| `add!(a, b)` | Фрагменты `expr` и подстановка выражений |
| `make_vec![...]` | Повторения `$(...),*`, пустой ввод и trailing comma |
| `hashmap! { key => value, ... }` | Решение практической задачи со слайдов в одну строку тела |
| `using_a!(a, a / 10)` | Гигиену и явную передачу `ident` |

Для `hashmap!` используется вариант решения со слайда:

```rust
::std::collections::HashMap::from([$(($key, $value)),*])
```

Внутренние имена, создаваемые `macro_rules!`, гигиеничны: они не захватывают случайно переменные места вызова. В `using_a!` идентификатор `a` передаётся аргументом, поэтому объявление и выражение получают одинаковый синтаксический контекст.

## Процедурные макросы

Каталог `proc-macros/` — отдельный crate с `proc-macro = true`:

- `identity!` — function-like макрос, возвращающий входной `TokenStream`;
- `#[keep]` — attribute-like макрос, сохраняющий аннотированный элемент;
- `#[derive(Count)]` — derive-макрос, разбирающий `syn::DeriveInput` и генерирующий `Enum::count()` через `quote!`.

`Count` решает практическую задачу из [репозитория со слайда](https://github.com/vitvakatu/proc-macro-example): подсчитывает варианты перечисления, включая unit-, tuple- и struct-варианты. Для других типов макрос выдаёт понятную ошибку компиляции. Тесты также проверяют пустой enum и обе формы атрибута — с аргументами и без них.

Примеры `serde` и `structopt` со слайдов не воспроизведены: это демонстрации возможностей внешних библиотек, а не реализации макросов самого занятия.

## Запуск

```bash
cargo run --example demo
cargo test
```

Основной crate не имеет внешних сетевых зависимостей. Proc-macro crate использует `syn 2` и `quote 1`, как показано в материалах занятия.
