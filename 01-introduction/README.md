# Занятие 1. Знакомство с Rust. Подготовка к обучению

Первая программа на Rust: установка тулчейна, создание проекта через `cargo` и базовый синтаксис.

## Что демонстрирует

- создание проекта: `cargo new introduction`
- сборка и запуск: `cargo build` / `cargo run`
- объявление переменных: неизменяемый `let` и изменяемый `let mut`
- базовые скалярные типы: целые числа, числа с плавающей точкой, `bool`, `char`
- вывод в консоль через `println!` и интерполяцию `{var}`

## Запуск

```bash
cargo run --example demo
```
