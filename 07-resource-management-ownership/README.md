# Занятие 7. Управление ресурсами. Принцип владения

Пример по презентации занятия: ресурсы и RAII, виды оперативной памяти, владение, перемещение, клонирование и `Copy`.

## Что демонстрирует

- статическую память на примере `static`;
- локальные данные на стеке и данные `String` в куче;
- размеры `String`, `&str`, чисел и массивов через `size_of`;
- RAII и автоматический вызов `Drop::drop` при выходе владельца из области видимости;
- перемещение `String` при присваивании;
- глубокое копирование строки через `clone`;
- передачу владения в функцию и возврат значения из неё;
- копирование значения типа `i32`, реализующего `Copy`.

После перемещения `String` прежняя переменная больше не используется: это соответствует правилу единственного владельца. Клонирование, напротив, создаёт независимую строку с отдельной аллокацией в куче.

## Запуск

```bash
cargo run
```

Запуск тестов:

