# Занятие 14. Практика: структуры, перечисления, pattern matching

Решения упражнений из PDF и пятиэтапной задачи «Термостат» по ссылке из презентации.

## Pattern matching

- завершение `traffic_light` обработкой неизвестного цвета;
- определение ошибочных вариантов `HttpStatus`;
- сумма двух `Option<i32>` через сопоставление кортежа;
- оценки через диапазоны `match`;
- исправление частичного перемещения `Foo` с помощью сопоставления по ссылке;
- рекурсивное перечисление `Expression` и вычисление выражения;
- перечисление `Asset` с данными разных видов актива.

## Термостат

Финальная версия включает все пять этапов:

- режимы `Heating` и `Cooling`;
- статусы `Off`, `Idle` и `Active`;
- отдельные уставки нагрева и охлаждения;
- включение, выключение и сохранение последней известной температуры;
- гистерезис, предотвращающий переключения внутри зоны нечувствительности;
- методы изменения режима, уставок и гистерезиса.

Из дополнительных заданий реализованы `info()` и подсчёт переходов `Idle → Active` через `activation_count()`.
