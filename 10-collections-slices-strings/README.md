# Занятие 10. Коллекции. Слайсы, массивы, строки

Работа со слайсами и ссылками на элементы коллекций.

## Что демонстрирует

- получение мутабельной ссылки на элемент кортежа по условию (`choose_elem`)
- индексация слайсов: `&mut [i32]`, срез массива (`[..3]`)
- unit-тесты на оба случая

## Запуск

```bash
cargo test
```
