# Занятие 6. Практика: типы данных, переменные, ветвление, циклы

Решения шести задач из презентации занятия. Пример использует только стандартную библиотеку Rust.

## Что демонстрирует

- `FizzBuzz`: преобразование числа в строку и построение списка результатов для диапазона `1..=n`;
- произведение цифр: игнорирование нулей и повторение операции до получения одной цифры;
- числа Фибоначчи: итеративное вычисление элемента и построение последовательности;
- уникальная цифра: подсчёт цифр и вариант для произвольной строки с результатом `Option<u8>`;
- отсутствующее число: использование суммы арифметической прогрессии;
- скобки: проверка правильной вложенности с помощью стека на `Vec<char>`.

В тестах сохранены примеры из исходных заготовок и добавлены проверки дополнительных функций и граничных случаев.

## Запуск

```bash
cargo run
```

Запуск тестов:

```bash
cargo test
```
