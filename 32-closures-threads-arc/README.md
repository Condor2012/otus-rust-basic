# Занятие 32. Лямбды и потоки. Send + Sync. move и Arc

Примеры передачи данных в потоки через каналы `std::sync::mpsc` и захвата окружения `move`-замыканиями.

## Что демонстрируют примеры

- `demo` — простейший обмен: поток получает владение отправителем и значением через `move`, вычисляет результат и отправляет его в основной поток; `join` ожидает завершение потока, а `recv` получает сообщение.
- `channel` — несколько потоков с клонированными отправителями: `Sender` реализует модель Multi-Producer-Single-Consumer, а `drop(tx)` закрывает исходного отправителя, чтобы итерация по каналу завершилась после завершения остальных.

Порядок сообщений от независимых потоков не гарантирован.

## Запуск

```bash
cargo run --example demo
cargo run --example channel
```

Внешние зависимости не используются.
