# Занятие 32. Лямбды и потоки. Send + Sync. move и Arc

Примеры передачи данных в потоки через каналы `std::sync::mpsc`.

## Что демонстрирует

- `src/main.rs` — простейший обмен: поток отправляет значение через канал, main получает его (`move`, `join`, `recv`)
- `src/channel.rs` — несколько потоков с клонированным отправителем, `drop(tx)` для завершения приёма, итерация по каналу

## Запуск

```bash
cargo run
cargo run --bin channel
```
