# Занятие 3. Типы данных. Переменные и функции

Примеры кода по презентации «Rust Developer. Basic. 3 Типы данных. Переменные и функции».

## Что демонстрирует

- Переменные: `let`, аннотация типа, `mut`, затенение (shadowing)
- Целочисленные типы и числовые литералы (`0xff`, `0b…`, `0o…`, суффиксы типов)
- Арифметика и побитовые операции
- Переполнение: `checked_add`, `wrapping_add`, `overflowing_add`, `saturating_add`
- Числа с плавающей точкой `f32`/`f64` и их методы
- `bool`, `char`, приведение типов через `as`
- Единичный тип `()`, массивы, безопасный доступ через `.get()`
- Строки: `&str` и `String`, основные операции
- Функции: возвращаемое выражение, ранний `return`, функция как аргумент
- Константы `const` и `const fn`

## Запуск

```bash
cargo run
```
